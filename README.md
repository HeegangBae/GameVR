# Turn-based RPG Game Planning (Unreal Engine 5)

## 1. 게임 개요

| 항목 | 내용 |
| :--- | :--- |
| **게임 제목** | Arena of Fate (턴제 RPG 프로젝트) |
| **장르** | 3D Turn-based RPG / Strategy |
| **개발 엔진** | Unreal Engine 5.4.4 |
| **플랫폼** | PC |
| **플레이 방식** | Single Player (1인용) |
| **시점** | 3D Quarter View / Fixed Camera |
| **예상 플레이 시간** | 5~10분 |

### 한 줄 소개
아레나 공간에서 몬스터와 턴을 주고받으며, 스킬과 속성을 활용해 적을 모두 처치하는 3D 턴제 전투 게임

---

## 2. 게임 컨셉

플레이어는 이세계의 아레나에 소환된 모험가가 되어, 몰려오는 몬스터들과 1:1 또는 파티 단위의 턴제 전투를 벌인다.
플레이어는 매 턴마다 '일반 공격', '스킬 사용', '아이템 회복' 중 하나를 선택할 수 있으며, 적의 속성과 남은 체력을 고려하여 전략적으로 행동해야 한다.
모든 적을 처치하면 승리하고, 플레이어의 체력이 0이 되면 게임 오버가 된다.

### 핵심 키워드
*   **Strategy** : 속성 상성과 턴 순서를 고려한 전략적 선택
*   **Command** : UI 기반의 명확한 커맨드 입력 시스템
*   **Combat** : 카메라 셰이크와 이펙트를 동반한 타격감 있는 턴제 전투
*   **Victory** : 적 처치 및 스테이지 클리어 성취감

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.
1. 게임 시작 시 아레나(전투 맵)에 진입한다.
2. 플레이어 턴에 UI 커맨드를 통해 행동(공격/스킬 등)을 선택한다.
3. 적의 패턴과 턴을 확인하며 데미지를 계산한다.
4. 모든 적의 체력을 0으로 만들어 처치한다.
5. 승리 화면(Victory UI)을 출력하고 게임을 클리어한다.

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

전투 시작 (스테이지 진입)
  ↓
플레이어 턴 시작 (커맨드 UI 활성화)
  ↓
행동 선택 (공격 / 스킬 / 아이템)
  ↓
플레이어 액션 실행 및 데미지 판정
  ↓
적 생존 여부 확인
  ├─ [적 생존] → 적 턴으로 전환 (적 공격 및 피격 연출)
  └─ [적 사망] → 승리 (Victory) 화면 출력 및 게임 종료

플레이어는 게임이 종료될 때까지 플레이어 턴과 적 턴의 공방을 반복한다.

## 5. 플레이어 조작

| 입력 | 기능 |
| :--- | :--- |
| **Mouse Left Click** | UI 버튼 클릭 (스킬 선택, 공격 대상 지정 등) |
| **ESC** | 일시정지 메뉴 열기 / 닫기 |

*※ 턴제 장르의 특성상 복잡한 키보드 조작 대신 마우스 위주의 직관적인 UI 인터랙션 중심 레이아웃 적용*

---

## 6. 플레이어 기능

### 6.1 전투 시스템
*   **턴 관리 (Turn System):** 플레이어와 적의 속도(Speed) 또는 순서에 따라 턴을 번갈아 가며 진행하는 상태 관리(State Machine) 구조.
*   **커맨드 선택:**
    *   **일반 공격:** 기본 데미지를 주는 확정 공격.
    *   **특수 스킬:** 마나(MP)를 소모해 더 강력한 피해를 주거나 버프/디버프 부여.
    *   **아이템:** 체력 포션 사용 등 생존 유도.

### 6.2 UI / 연출 시스템
*   **동적 HP/MP 바:** 체력 증감에 따라 실시간으로 줄어드는 UMG 체력바 위젯 연동.
*   **전투 텍스트 로그:** 화면 하단에 "플레이어의 공격! 적에게 25의 데미지!" 같은 텍스트 로그 출력.
*   **타격 연출:** 공격 적중 시 카메라 셰이크(Camera Shake)와 파티클 이펙트 발동.
